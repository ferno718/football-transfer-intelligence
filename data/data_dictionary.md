
# Data Dictionary

## 1. Players

| Column | Description |
|---|---|
| player_id | Stable generated player-season identifier |
| player | Player name |
| nation | Nationality |
| position | Source position |
| club | Club name |
| league | Competition |
| season | Season label |
| age | Age value from source |
| minutes | Minutes played |
| goals | Goals scored |
| assists | Assists recorded |
| shots | Total shots |
| shots_on_target | Shots on target |
| tackles_won | Tackles won |
| interceptions | Interceptions |
| source | Data source provenance |
| source_url | Original source URL |

## 2. Analyses

Stores saved player-level analytical snapshots, including impact and fit fields, analytical drivers and a JSON result payload.

## 3. Comparison History

Stores selected player IDs and names, selected metrics and JSON comparison payloads for reproducibility.

## 4. Recruitment Shortlist

Stores recruitment workflow information, including notes, priority, status and target role.

## 5. User Inputs

Stores manually entered scouting and transfer-planning records.

Transfer fees and wage values are user-entered references, not verified market values.

## 6. Source Registry

Stores source identity, URL, coverage information and licensing notes.
